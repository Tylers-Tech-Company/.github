# Tyler’s Tech Company GitHub configuration

Organization-level GitHub documentation and community defaults for Tyler’s Tech Company.

## Repository contents

- [`profile/README.md`](profile/README.md) — public organization profile shown at [github.com/Tylers-Tech-Company](https://github.com/Tylers-Tech-Company)
- Future files under `.github/` may provide shared issue templates, pull-request templates, security guidance, or contribution defaults for repositories that do not define their own

## Maintenance

Changes to `profile/README.md` are immediately public after merge. Before publishing:

1. Verify all domains, email addresses, and service descriptions.
2. Include only public products and repositories.
3. Exclude client names, infrastructure details, credentials, internal hostnames, and private-repository links.
4. Preview the Markdown and check every link.
5. Use a pull request for review.
